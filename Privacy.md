RoboFish Privacy Policy

Effective Date: June 25, 2026

This Privacy Policy explains what information RoboFish collects, how it is used, and how server owners or users can request removal of data.

RoboFish is a Discord bot. It is not affiliated with, endorsed by, or operated by Discord Inc.

1. Information RoboFish May Collect

RoboFish may collect and store limited information needed for bot features to work.

This may include:

- Discord server IDs.
- Discord channel IDs.
- Discord message IDs.
- Discord role IDs.
- Discord user IDs.
- Server configuration settings.
- Role Menu configuration data.
- Suggestion records submitted through RoboFish.
- Game-related settings or records.
- Uploaded backgrounds, images, or text used for Role Menu features.
- Message metadata needed to track bot-created messages.

RoboFish generally stores Discord IDs, configuration values, uploaded server assets, and bot feature records. RoboFish does not intentionally collect sensitive personal information.

2. Uploaded Images, Backgrounds, and Custom Text

RoboFish may allow server administrators or authorized users to upload or provide background images, header images, custom text, or other visual assets for Role Menu features.

These uploaded files or provided text may be stored by RoboFish in order to:

- Generate custom role menu images.
- Create previews.
- Save server-specific visual settings.
- Allow the same uploaded asset or generated image to continue working after setup.

Uploaded images, backgrounds, and custom text are used only for the purpose of providing the requested RoboFish feature for the server in which they were uploaded, unless otherwise clearly stated.

RoboFish does not claim ownership of uploaded images, backgrounds, or custom text.

The user or server uploading content is responsible for ensuring they have permission to upload and use that content.

RoboFish does not reuse uploaded images or backgrounds for other servers, public display, or unrelated purposes without permission.

Uploaded files may remain stored until they are replaced, deleted, no longer needed for the related feature, or removed upon request.

3. Message Content

RoboFish may process message content only when needed for specific features, such as Role Menus, Suggestions, Games, setup flows, or compatibility features.

RoboFish does not use message content for advertising.

RoboFish does not sell message content or user data.

4. How RoboFish Uses Data

RoboFish uses stored data to:

- Provide Role Menu features.
- Run suggestion systems.
- Run game features.
- Track bot-created messages for cleanup.
- Save server configuration.
- Debug errors and improve reliability.
- Prevent abuse and maintain bot security.

5. Data Sharing

RoboFish does not sell user data.

RoboFish data is not shared with advertisers.

Data may be visible to RoboFish’s developers for support, debugging, maintenance, or abuse prevention.

Data may also be processed by services required to operate RoboFish, such as Discord and hosting or database providers.

6. Data Storage

RoboFish stores data in a database controlled by the bot’s developers.

Data is kept only as long as needed for RoboFish features, maintenance, abuse prevention, or support.

Some data may be deleted automatically when related bot-created messages are deleted, where supported by RoboFish.

7. Data Removal

Server owners or authorized administrators may request removal of their server’s RoboFish data.

Users may also request review or deletion of data associated with their Discord user ID, where possible.

To request data removal, contact:

[Your support email or support server link]

Please include:

- Your Discord user ID.
- The Discord server ID, if the request is server-related.
- A description of what data you want removed.

8. Server Owner Controls

Server owners can remove RoboFish from their server at any time.

Removing RoboFish may stop new data collection, but it may not automatically delete all previously stored configuration or feature data. Contact support to request full server data deletion.

9. Security

Reasonable steps are taken to protect RoboFish data. However, no system is completely secure, and no guarantee can be made that data will never be accessed, lost, or altered.

10. Children’s Privacy

RoboFish is intended for use within Discord servers and follows Discord’s platform rules. RoboFish is not intended to knowingly collect personal information from children outside what Discord provides through normal bot operation.

11. Changes to This Policy

This Privacy Policy may be updated from time to time. Continued use of RoboFish after changes means you accept the updated policy.
